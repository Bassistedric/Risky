# Risky QHSE — Demo V0.1

Prototype web du futur environnement interne de gestion QHSE Risky.

## Objectif

Cette première version sert de démonstrateur fonctionnel et UX : navigation complète, tableau de bord et données fictives. Elle ne contient aucune donnée réelle d'entreprise.

## Architecture de principe

Risky est conçu pour séparer :
- le moteur applicatif ;
- la configuration de l'organisation ;
- les données de l'organisation ;
- les connecteurs de stockage futurs (SharePoint, SQL Server, PostgreSQL, etc.).

## Démo

Le projet est volontairement statique pour pouvoir être publié sur GitHub Pages sans serveur ni installation locale.

Prochaines étapes : parcours Accident → Actions, Analyse de risques → Mesures → Actions et Machine → Risques → Contrôles.
